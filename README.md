# ☕ Tea Time – Artisan Tea & Coffee Lounge

Tea Time is a stylish tea and coffee lounge website designed to provide a relaxing online browsing and ordering experience. It showcases artisanal teas, handcrafted coffee, and gourmet snacks through an elegant interface with interactive features and a café-inspired design.

## ✨ Features

- **Responsive Design** – Designed for a smooth browsing experience across different screen sizes.
- **Image Slider** – A four-slide hero banner showcasing tea, coffee, afternoon tea, and pastries.
- **Interactive Menu** – Browse tea, coffee, and snack collections.
- **Category Filtering** – Filter products by tea, coffee, or snacks.
- **Search Functionality** – Search for tea, coffee, and snack items.
- **Shopping Cart** – Add products to your cart and manage your order.
- **Order Summary** – View subtotal, tax, and total price.
- **Gourmet Snacks Section** – Featuring croissants, scones, macarons, and almond biscotti.
- **Customer Testimonials** – A dedicated section showcasing customer reviews.
- **Elegant UI** – A modern café-style design with attractive imagery and typography.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/sayanac1212/TEATIME-WEBSITE.git
```

### 2. Navigate to the project folder

```bash
cd TEATIME-WEBSITE
```

### 3. Run the website

Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.
